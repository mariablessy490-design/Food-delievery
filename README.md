
# Project Overview
A food delivery app that helps users easily discover restaurants, choose their favorite food, place orders, and track deliveries from their mobile phone.

# Objective
1.To make food ordering simple and fast.
2.To provide an easy-to-use interface for users.
3.To help users find restaurants and food quickly.
4.To provide a smooth and convenient ordering experience.

# Features
1.User Login / Sign Up
2.Restaurant & food search
3.Food categories
4.Food details and prices
5.Add to Cart
6.Online Payment
7.Order Confirmation
8.Live Order Tracking
9.Order History
10.Ratings & Reviews

# Design Highlights
1.Clean and attractive UI
2.Simple navigation
3.Attractive food images
4.Clear buttons and icons
5.Easy-to-read fonts
6.Consistent colors and spacing
7.Mobile-friendly design

1. Splash Screen → App logo
2. Login / Sign Up → User authentication
3. Home Page → Categories & restaurants

5. Cart → Selected food items
6. Checkout → Address & payment
7. Order Tracking → Track delivery
8. Profile → Orders, reviews & settings
